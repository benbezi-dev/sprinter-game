# Monuments de la Légende — sources

Chaque monument est un modèle Tripo (Modèle HD H3.1) généré d'après l'image
ci-dessous, puis rendu dans Blender (`tools/blender/decors/legende_monuments.py`).
Les photos viennent de Wikimedia Commons ; leurs licences demandent
l'attribution (BY) et, pour BY-SA, le partage des œuvres dérivées sous la même
licence. **À reprendre dans les crédits du jeu avant toute ouverture publique.**
