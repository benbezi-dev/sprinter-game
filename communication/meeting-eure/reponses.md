# Meeting de l'Eure — les réponses prêtes

> Le DM est parti le 28/11/2026. Chaque réponse tient en un seul message
> Instagram (moins de 1000 caractères). Les crochets sont à remplir.

## Avant de répondre

- **Le prix.** Ne pas l'improviser. Décider avant l'appel : gratuit pour
  une première édition (vitrine et contenu pour Sprinter), ou un tarif
  pour les panneaux partenaires. Les prix de `../offre-panneaux.md` sont
  encore vides.
- **Les chiffres d'audience** (joueurs actifs, courses par semaine) : les
  relever sur le tableau d'activité avant l'appel. On les demande presque
  toujours.
- **Le délai.** Le « Défi du Meeting » n'existe pas encore dans le jeu. Pour
  un lancement le 23/01, il faut un accord vers la mi-décembre.

## C · « Comment ça marche concrètement ? Il faut télécharger une appli ? »

```
Le jeu est gratuit et se joue aussi directement dans le navigateur, sans téléchargement ni inscription : un lien ou un QR code suffit.

Le joueur choisit un pseudo, court le 60 m dans la salle Jesse Owens en alternant deux touches, et son chrono entre au classement. Les duels se lancent en partageant un lien.

De votre côté, rien à installer : je m'occupe du défi, du classement et des panneaux. Il vous suffit de relayer le lien sur vos réseaux et, si vous le souhaitez, de l'afficher dans la salle.
```
